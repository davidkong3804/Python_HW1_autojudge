1載入學生程式

把學生的繳交檔拖進來

幾十份一起拖也可以；COOL 整包下載的「zip 裡面還有 zip」也吃得下。散裝 .py、整個資料夾同樣支援。

修課名單 選用
檔名怎麼取？（自動辨識規則）
  • 公告格式：B11901234_HW2.zip → B11901234_HW2/q1a.py …，學號與題號都會自動抓出來。
  • COOL 下載的檔名被加料也沒關係：wang_98765_43210_B11901234_HW2.zip 一樣抓得到 B11901234。
  • 其他寫法：B11901234_q3.py、hw1_3.py、第3題.py；有子題的作業認得 q1a、q1_a、Q1(a)、1a。
  • 有子題的作業只寫 q1.py 分不出 a 還是 b，會標成「待指定」，請展開選題號。
  • 萬一有人交 Colab 的 .ipynb：會自動拆成一格一格的 code cell（!pip、%magic 會被略過），再用「自動配對」判斷每一格是哪一題。
  • 修課名單：COOL 或 Excel 匯出的 CSV 都可以，只要有一欄是學號，旁邊的姓名欄會一起讀進來。

3批改

評分標準 設定一次就好，全班用同一套；批改後再改會提醒重批
答案對，但多印了說明文字或提示字 例：應輸出 55.56，同學印成 BMI = 55.56
先不給分，標成「格式不符」；批完在成績表逐位打勾就給分
空白或大小寫不一樣 例：應輸出 Weak，同學印成 weak 或  Weak（行尾空白一律不算錯）
答案印對了，但程式最後才出錯 例：印完答案又多寫一行 input('按 Enter 結束')
更多設定（通常不用動）
每筆測資最多跑幾秒 超過就算「執行逾時」。同學的程式很慢（例如質數一路試到 n）才需要調大
一行的輸入，同學拆成好幾次 input() 讀 老師規定一行就是一次 input()，所以預設算錯。選「接受」會把那一行拆開重跑一次

測資與配分設定 進階

可以關掉某些測資、加自己的測資、改每題配分（每份作業各自一套）。題目總分固定，啟用中的測資平分—— 關掉一組不會讓總分變少，而是讓剩下的每一組變重。設定存在這台瀏覽器裡，換電腦或換助教請用下面的匯出／匯入。

題目配分啟用測資每組分數
自訂測資的正確輸出是怎麼來的？
  • 助教只要輸入 input，正確輸出由這個頁面實際執行參考解答產生， 和 tools/generate_tests.py 的做法一致——答案不是手打的，不會打錯。
  • 參考解答跑這筆輸入會出錯（例如格式不合題目規定），就不會讓你加進去，並且會把錯誤訊息顯示出來。
  • 多行輸入請一行一行打；送出前會照題目的格式跑一次給你看結果。
  • 匯出的 JSON 可以交給命令列版：python3 tools/grade_cli.py 繳交資料夾/ --hw hw2 --config 設定.json， 讓兩邊用同一套設定，不會算出不同的成績。

檔名怎麼取？（自動辨識規則）
  • 公告格式：B11901234_HW1.zip → B11901234_HW1/q1.py ~ q6.py，學號與題號都會自動抓出來。
  • COOL 下載的檔名被加料也沒關係：wang_98765_43210_B11901234_HW1.zip 一樣抓得到 B11901234。
  • 其他寫法：B11901234_q3.py、hw1_3.py、第3題.py 也認得。
  • 萬一有人交 Colab 的 .ipynb：會自動拆成一格一格的 code cell（!pip、%magic 會被略過），再用「自動配對」判斷每一格是哪一題。
  • 認不出來也沒關係，下面的表格可以直接用下拉選單改。
